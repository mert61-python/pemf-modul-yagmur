# KART bilgi formu

Bu formu kendi kartınız için doldurun. Aynı bilgiler `modul.json` dosyasının `kart` alanında da bulunmalıdır.
Kabul testi, formdaki değerleri kartın gerçek davranışıyla karşılaştırır. Boş alan bırakmayın; bilinmeyen değer için "ölçülmedi" yazın.

| alan | değer |
|---|---|
| Geliştirici (ad, e-posta) | |
| Mikroişlemci (model, saat) | |
| Kart yazılımı (depo / sürüm) | |
| Sürme kartı (model, kanal sayısı) | |
| Bağlantı (seri / Wi-Fi / BLE / USB) | |
| Kartı bulma yöntemi (USB VID / PID / seri no; Wi-Fi'de IP / ad) — ana PEMF kartının portu AÇILMAZ | |
| Bobin (sarım, direnç Ω, endüktans mH, çap mm) | |
| Güç kaynağı (V) ve akım sınırı (A) | |
| Parametre sınırları (frekans Hz, duty %, şiddet %, süre dk) — kartta da uygulanır | |
| Bekçi süresi (`bekci_ms`, en az 1500; sunucu 500 ms'de bir kalp atışı gönderir) | |
| Açılış durumu (bobin KAPALI olmalı) | |
| ACİL DURDUR yolu (ayrı kanal mı? ölçülen kesme süresi ms) | |
| Bağlantı koparsa kartın davranışı | |
| Lisans (kart yazılımı + sürücü + panel) | |
